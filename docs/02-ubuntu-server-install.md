# Ubuntu Server Installation

## Recommended Version

Install **Ubuntu Server 24.04 LTS**.

## Installer Choices

During installation:

- Use the normal/minimal server install
- Do not install a desktop environment
- Use the full 256GB SSD
- Enable OpenSSH server
- Skip optional snap packages for now
- Set a clear hostname, such as `homelab` or `k3s-01`

## Why Ubuntu Server?

Ubuntu Server is widely used, well documented, and has strong compatibility with k3s, Docker/container tooling, networking utilities, and common homelab software.
